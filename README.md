# StudentStats-Backend

This is a Backend Server for the StudentStats project.

It is built using GO and uses the Gin framework for routing and handling HTTP requests.

Its purpose is to provide a RESTful API for managing Students, Courses, Grades, Schedules and other related data.

It is designed to be used in conjunction with a Frontend application for Backoffice management of pertinent entities, and with a simple Frontend Application meant to be embedded on IoT devices with RFID scanning.
